# 🛒 Zepto Sales Analytics Dashboard

## 📌 Project Overview

This project is an interactive Power BI dashboard built to analyse Zepto sales and business performance. The dashboard provides insights into orders, sales, customer behaviour, product performance, delivery efficiency, discounts, and inventory status. It helps identify business trends and supports data-driven decision-making through interactive visualisations.

---

## 🎯 Objectives

- Analyse overall sales performance.
- Track total orders and quantity sold.
- Identify top customers by sales.
- Analyse delivery time across different cities.
- Monitor daily order trends.
- Evaluate order status distribution.
- Identify best-selling products.
- Monitor average discounts and out-of-stock items.

---

## 📊 Dashboard Features

### KPI Cards
- Total Orders
- Total Quantity Sold
- Total Sales
- Average Delivery Time
- Average Discount
- Out of Stock Items

### Visualisations
- Top Customers by Sales
- Delivery Time by City
- Daily Order Trend
- Order Status Distribution
- Top Products by Sales

---

## 📈 Key Insights

- Identifies the highest revenue-generating customers.
- Shows city-wise delivery performance.
- Highlights daily ordering trends.
- Displays delivered, cancelled, and returned orders.
- Identifies the best-selling products.
- Monitors inventory shortages and average discounts.
